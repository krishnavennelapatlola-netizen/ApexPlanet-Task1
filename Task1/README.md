# Athul K K - Personal Portfolio

A responsive personal portfolio website developed as part of the ApexPlanet Software Pvt. Ltd. Full Stack Web Development Internship.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Git & GitHub

## Features

- Responsive portfolio design
- About Me section
- Technical skills
- Project showcase
- Education timeline
- Workshops and learning
- Contact form with JavaScript validation
- PHP and MySQL Student Management System

## Local Setup

1. Install XAMPP.
2. Start Apache and MySQL.
3. Place the project inside the XAMPP `htdocs` folder.
4. Open the portfolio through the local Apache server.
